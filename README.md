# Portafolio web

Portafolio personal de Roberto González, estudiante de Ingeniería en
Informática de la Universidad Católica de Temuco. El sitio presenta el perfil,
información de contacto y una colección de proyectos frontend.

## Ver el portafolio

El sitio está publicado con GitHub Pages:

<https://rgonzalez2026-ui.github.io/Portafolio-Roberto-Gonzalez/>

Para ejecutarlo localmente, inicia un servidor estático desde esta carpeta:

```powershell
py -m http.server 5500
```

Luego abre <http://localhost:5500>.

## Proyectos incluidos

| Proyecto | Descripción |
| --- | --- |
| Mi portafolio | Página personal con presentación, proyectos y formulario de contacto. |
| Nova | Boceto interactivo para organizar ideas y visualizar el progreso de proyectos. |
| Prestige Legal | Landing page para una asesoría legal, con una estética editorial y profesional. |
| Promar | Catálogo web de insumos para sushi con productos destacados y carrito interactivo. |

Todos los proyectos están enlazados desde la sección **Proyectos destacados**
de [`index.html`](./index.html).

## Tecnologías

- HTML5 semántico.
- CSS3 responsive, con variables, grid y flexbox.
- JavaScript para las interacciones de Nova y Promar.
- Google Fonts.
- Tailwind CSS mediante CDN en Prestige Legal.
